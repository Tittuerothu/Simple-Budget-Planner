# Simple Budget Planner

A modern personal finance and expense tracking mobile application developed using Flutter, designed to help users efficiently manage income, expenses, and category-based budgeting through a clean and responsive user interface.

The application provides real-time financial tracking, expense categorisation, spending insights, and budget management features to support better personal financial planning and decision-making.

---

# Overview

This project was developed to provide users with a lightweight and user-friendly budgeting solution capable of tracking daily financial activities and analysing spending behaviour.

The application focuses on delivering a seamless mobile experience through responsive UI design, structured state management, and intuitive expense management workflows.

The system demonstrates practical implementation of:

* Mobile application development
* Financial data management
* Real-time state updates
* User-centric interface design
* Budget tracking and analytics
* Cross-platform mobile development
